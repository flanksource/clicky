## What gets generated

| From one `NewEntity` registration | You get |
| --- | --- |
| `List` + `ListOpts` flags | `app widgets [--flags]`, `GET /api/v1/widgets`, a filterable table in clicky-ui |
| `Get` | `app widgets get <id>`, `GET /api/v1/widgets/{id}` |
| `Create` / `Update` / `Delete` | `create key=value…`, `update <id> key=value…`, `delete <id>` plus the matching `POST`/`PUT`/`DELETE` routes |
| `Filters` | typed flags, shell completion, a `?__lookup=filters` endpoint that drives the UI filter bar |
| `WithAction` / `WithBulkAction` | `app widgets restart <id>`, `POST /api/v1/widgets/{id}/restart`, selection-toolbar buttons |
| Tool hints | MCP tool annotations, approval defaults and grouping for AI clients |
